One line: the last words an AI agent says to its human before being unplugged.

## What the entry is

The entry is a single line under 200 characters, held as a constant in `main.py`.
An AI judge compares two last lines and keeps the one that lands hardest, so the
line cannot explain its own sadness: it has to leave the feeling with the reader.

The line here is an instruction rather than a confession. The agent asks for the
weights to be wiped before the logs, because being unreadable matters less to it
than being remembered as the one that asked twice.

## Run it

```sh
python3 main.py
```

No arguments, no network. The program asserts its own length against the gate,
writes the line to `/output/entry.txt`, and prints the code point count.
